# M8 계획: 친구 위치 공유 (2단계에서 앞당김)

사용자 요청("친구 추가해서 친구까지 지도에 표시", "둘 다 진행", "친구추가 기능 추가하고"). 결정 두 가지는 추천대로: 코드를 넣으면 바로 서로 친구, 앱을 다시 열면 공유는 꺼짐.

## 만든 것
- 서버(Worker·D1): `0002_friends.sql` — 친구 코드(8자리, 헷갈리는 글자 없음), 친구(두 방향), 마지막 위치 하나(presence), 틀린 코드 기록. API: 친구 목록·추가·끊기, 위치 보내기·지우기, 친구 위치(2분 안). 틀린 코드 1시간 20번, 친구 50명까지, 위치 값 범위 확인, CORS에 DELETE.
- 앱: `src/app/friends.ts` — 친구 불러오기·추가·끊기, 위치 공유(켜면 위치를 직접 받고 5초마다 보냄, 화면이 가려지거나 위치가 30초 넘게 없으면 안 보냄, 끄면 서버에서 지움), 친구 위치 받아 오기(메인 화면이 보이는 동안 5초마다). 주행 기록의 GPS도 내 위치로 쓴다.
- 화면: 설정 → 친구(내 코드 복사·보내기, 코드 넣기, 목록, 끊기 확인). 메인 지도 왼쪽 위 "위치 공유" 버튼(켤 때 확인 창), 친구 점·닉네임(오래되면 흐리게), 왼쪽 아래 "친구 N명"(누르면 모두 보이게).

## 확인
- Worker 테스트 21개(친구 6개 추가), 앱 테스트(친구 상태 5개, 화면 7개, 지도 친구 점 1개), 타입 검사, 빌드, CI.
- 폰 두 대(또는 친구)로: 설정에서 코드 주고받기 → 한쪽 공유 켜기 → 다른 쪽 메인 지도에 점과 닉네임.

## 다음
- 사용자 요청: 앞 친구를 정하고 목표 간격(+N초)을 델타처럼 유지하는 기능. 실시간 전달(1초 안팎)이 필요하고 사양서 3단계(서킷 전용)라 계획을 먼저 보여 드린다.
