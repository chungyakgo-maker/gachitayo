# M9 계획: 앞 친구 간격(초) + 재생 모드 지도

사용자 요청: "앞에 친구와 델타값을 지정해서 앞차와의 차간거리를 델타 +값으로 유지 (초 단위)", "재생모드에서도 비율상 예쁘게 확대된 지도 위에".
결정(사용자): 어디서나 쓰되 목표 간격 1초 이상·처음 켤 때 안전 안내 / 큰 델타 자리에 간격 차이(베스트 델타는 작게) / 재생 지도는 전체 코스·따라가기 둘 다.

## 만든 것
1. 재생 모드 지도: OSM 지도(어둡게) 위에 오버레이 그리기 함수로 코스·고스트·내 위치. 전체 코스(꽉 채움)·따라가기(17단계). 지도 조작은 끔(두 번 탭과 겹치지 않게).
2. 간격 계산 `engine/live/gap.ts` (순수): 앞 친구 최근 경로에서 내 자리를 가장 최근에 같은 방향으로 지난 시각. 마지막 위치 너머 늘려 계산, 내가 앞서면 —, 튄 점 하나 건너뛰기, 1초 부드럽게, 5초 끊기면 신호 없음.
3. 서버 실시간 방 `worker/src/live.ts` (Durable Object, 사람마다 하나): 본인은 보내기, 친구는 받기, 정해진 모양만 전달, 마지막 위치를 새 친구에게 바로. `/live/{userId}` WebSocket, 열쇠는 하위 프로토콜로.
4. 앱 `src/app/liveLink.ts`: 주행 시작·이어서 하기 때 연결(앞 친구 받기, 위치 공유 중이면 내 GPS 보내기), 끊기면 다시 붙기(최대 15초), 주행이 끝나면 닫기.
5. 화면: 주행 준비 "앞 친구 간격"(친구 칩, 목표 −/+ 0.5초, 1~10초, 안전 안내 한 번). 주행 화면 큰 숫자 = 지금 간격 − 목표(가까움 빨강·멂 초록·유지), 패널 오른쪽 지금 간격·작은 베스트 델타, 상단 칸 "앞 친구 간격", 지도에 앞 친구 점, 신호 없음 알림.
6. 덮는 창(안내·고르기)은 body에 붙인다 (아이폰 홈 화면 앱에서 어느 상자 안에서 열어도 화면 전체를 덮게).

## 확인
- 엔진: 서킷 3바퀴에서 간격 1·2·5초 오차 RMS < 0.2초, 와인딩에서 내가 앞서면 null, 왕복 길·튄 점에도 최대 오차 1초 미만, 신호 없음.
- 서버: 앞 친구 → 친구 전달, 늦게 붙은 친구에게 마지막 위치, 뒤차가 보낸 것 무시, 친구 아님 403·열쇠 없음 401·WebSocket 아님 426, 위치 모양 검사.
- 앱: 연결 주소·하위 프로토콜·GPS 보내기, 받은 위치 모으기·늦은 것 버리기·다시 붙기, 화면 표시, 준비 화면(안전 안내·목표 범위), 주행 화면 계산 연결.
- 실차: 폰 두 대로 앞차(위치 공유 켜고 주행)·뒤차(앞 친구 고르고 주행). 간격이 대략 맞는지, 끊겼을 때 알림.
