# M10 계획: 분석·내보내기·코스 관리·기록 지우기

사용자 확인: "m10 진행". 함께 받은 요청: 길게 눌러 종료 1초, 강조색 #AACAE6(N 퍼포먼스 블루 컨셉), 메인 새 코스 카드 작게, 기록 삭제.

## 작업
1. 기록 지우기 (폰 + 서버 표·파일, 대기열로 통신 없을 때도) — 완료
2. 내보내기 `src/export/` (순수): CSV(6.9 열 순서·단위), 랩 요약 CSV, GPX(세션·코스)
3. 분석 화면 (기록 탭 → 분석): 랩 목록, 두 랩 비교 그래프(속도·델타, 가로축 코스 거리), 속도 색칠 지도, G 다이어그램, 지점 정보, 내보내기
4. 코스 관리: 목록·상세, 이름 바꾸기, 출발선·도착선 옮기기(중심선 위, version+1 다시 계산), 지도에서 새 코스, GPX 불러오기·내보내기, 코스 지우기
5. 설정 나머지: 게이트 폭, 거치 팁

## 확인
- CSV 열 순서·이름·단위, utc_time 단조 증가, 비교 랩이 없을 때 delta_s 빈칸 (10.1)
- 화면 테스트, 폰 화면 캡처, 배포
