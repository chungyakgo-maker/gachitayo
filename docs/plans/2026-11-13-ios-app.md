# 아이폰 앱 "디고" (Capacitor 껍데기) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 지금 웹앱을 Capacitor로 감싸 아이폰 앱(디고)으로 빌드되게 하고, 앱에서 안 돌아가거나 애플 심사에 걸리는 부분(사양서 13.3)을 고친 뒤, GitHub 맥 서버에서 시뮬레이터 빌드와 화면 확인까지 한다.

**Architecture:** 같은 코드를 두 가지로 빌드한다. 웹(`vite build`, 지금 그대로)과 앱(`vite build --mode app` → `dist-app` → `cap sync ios`). 앱 전용 동작은 `src/platform.ts`의 `isApp()`이 참일 때만 켜고, Capacitor 플러그인은 그 갈래 안에서만 부른다. 계정 삭제·약관 페이지·서버 출처 허용은 웹과 앱 공통.

**Tech Stack:** Capacitor 8.6 (`@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`), `@capacitor-community/background-geolocation` 1.3, `@capacitor-community/keep-awake` 8, `@capacitor/filesystem` 8, `@capacitor/share` 8, `@capacitor/app-launcher` 8, React 19, Vite 8, Vitest, Cloudflare Worker.

**Spec:** `docs/specs/2026-11-12-gachitayo-phase1-spec.md` 13.3 "아이폰 앱 디고", 12 알려진 제약, 변경 이력 2026-11-13.

## Global Constraints

- 이름: 홈 화면·앱스토어 **디고**, 영문 **DGO**, 번들 ID **`com.dgo.app`**.
- 작업 갈래 `ios`. main에 합치기는 사용자 승인 뒤 (합치면 웹이 배포된다).
- 웹 빌드 결과는 그대로: `base: '/gachitayo/'`, 서비스워커(`sw.js`), 새 버전 배너, 개발자 메뉴, "홈 화면에 추가" 안내.
- 앱 전용 동작은 `isApp()`일 때만. 시험에서는 `vi.mock('../../src/platform', () => ({ isApp: () => true }))`로 켠다.
- 서버 허용 출처: 지금 `ALLOWED_ORIGIN` + `capacitor://localhost`. 그 밖은 지금처럼 403.
- Cloudflare: gachitayo 이름의 것만. 맥 서버 작업에서 Cloudflare는 Worker 주소를 알아내는 읽기만.
- 한국어 글·주석·커밋, 커밋 끝 두 줄(Co-Authored-By / Claude-Session).
- 약관 페이지의 연락처는 사용자에게 받기 전까지 "(출시 전에 채움)"으로 둔다. 이름·이메일을 지어내지 않는다.

## Review Focus

1. 메인 화면의 위치 미리보기(`useLocationPreview`)가 앱에서 백그라운드 위치를 켜면, 앱을 내려도 GPS가 돌아 배터리가 닳는다 → Task 3: 미리보기는 백그라운드가 아님을 시험.
2. 주행을 끝내는 `stop()`이 플러그인의 `addWatcher` 응답보다 먼저 오면 백그라운드 위치가 안 꺼진다 → Task 3 시험.
3. 계정 삭제 중 통신이 끊기면 서버는 남고 폰만 지워져 다시 지울 수 없다 → Task 6: 서버 실패 시 폰 기록 그대로, 오류 표시.
4. 주행(기록) 중 계정 삭제를 누르면 기록 중인 세션이 깨진다 → Task 6: 기록 중이면 거절.
5. 앱 출처에서 지도 정보·타일·글꼴 요청이 403이면 지도가 빈 화면 → Task 2: `capacitor://localhost`로 `/map/info` 시험.
