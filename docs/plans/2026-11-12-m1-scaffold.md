# M1 저장소 뼈대와 자동 배포 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 빈 웹앱이 GitHub Pages에 자동 배포되고, 폰에서 홈 화면에 설치되며, 통신 없이도 열린다.

**Architecture:** 저장소 루트 하나의 Vite + React + TypeScript 웹앱. 해시 라우팅. vite-plugin-pwa가 매니페스트와 서비스 워커를 만든다. 새 버전은 사용자가 "업데이트"를 눌러야 적용된다(주행 중 자동 새로고침 방지). `engine/`, `normalize/`, `gpx/`는 DOM 타입이 없는 별도 tsconfig로 타입 검사해서 사양서 5.1 규칙을 강제한다.

**Tech Stack:** Node 22, npm, Vite 8, React 19, TypeScript 5.9(strict), react-router 7(해시 라우터), vite-plugin-pwa 1.x, Vitest 4, @testing-library/react + jsdom, GitHub Actions(checkout v7, setup-node v7, configure-pages v6, upload-pages-artifact v5, deploy-pages v5)

**Spec:** `docs/specs/2026-11-12-gachitayo-phase1-spec.md` (4장 기술 스택, 5.1 규칙, 5.2 폴더 구조, 8장 공통, 11장 배포)

## Global Constraints

- 배포 주소: `https://chungyakgo-maker.github.io/gachitayo/` → Vite `base: '/gachitayo/'`
- 화면 문구는 한국어, 시각은 KST(기기 시간대와 무관)
- TypeScript `strict: true`
- `src/engine/**`, `src/normalize/**`, `src/gpx/**`: DOM·브라우저 API 사용 금지 (타입 검사로 강제)
- main 푸시 → 테스트 → 통과 시에만 Pages 배포. 테스트 실패 시 배포 중단
- Actions 변수 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_FILES_API_URL`를 빌드에 넘긴다 (M1에서는 비어 있어도 빌드 성공)
- 서비스 워커 갱신은 `registerType: 'prompt'` (사용자가 누를 때만 적용)

## Review Focus

1. 하위 경로(`/gachitayo/`)에서 매니페스트·아이콘·서비스 워커 경로가 깨지는 경우 → `vite preview`로 하위 경로에서 열어 확인
2. 통신 없이 홈 화면 앱을 다시 여는 경우 → 헤드리스 브라우저에서 오프라인 새로고침으로 확인
3. 아이폰 홈 화면 설치 시 전체 화면·아이콘 → 빌드된 `index.html`의 apple 메타 태그와 180px 아이콘 존재 확인
4. CI의 시간대가 UTC인 경우 KST 표시 → `formatKst` 테스트가 UTC 기준 시각으로 검증
5. Pages 소스가 "GitHub Actions"로 설정되지 않은 경우 → 배포 단계 실패. 사용자 설정 안내로 대응
