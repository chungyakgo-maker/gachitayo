# M2 기록기 (센서 수집, 폰 저장, 중단 복구) — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 아이폰·안드로이드에서 GPS와 모션 원본을 기록해 5초 단위로 폰에 저장하고, 앱이 중단돼도 이어서 기록하며, 원본 파일(6.7)로 내보낸다. 실기 플랫폼 점검(10.3-1)과 실데이터 수집이 목적이다.

**Architecture:** 브라우저 센서(`sensors/`) → 순수 변환(`normalize/`: 세션 시계, 샘플 변환) → 기록기(`storage/recorder.ts`: 버퍼, 5초 덩어리, 이벤트) → IndexedDB(Dexie). 화면과 센서를 잇는 기록 컨트롤러는 모듈 하나(싱글턴)로 두어 화면 전환과 무관하게 유지한다. 원본 파일 생성은 순수 함수, gzip은 `CompressionStream`.

**Tech Stack:** M1 스택 + Dexie 4.4.7, fake-indexeddb 6.2.6(테스트)

**Spec:** `docs/specs/2026-11-12-gachitayo-phase1-spec.md` (5.1, 6.1, 6.2, 6.3, 6.4, 6.7, 8.4 화면 꺼짐 방지, 9장 권한 거부·앱 중단·화면 꺼짐 방지 실패·저장 공간)

## Global Constraints

- 위치: `watchPosition`, `enableHighAccuracy: true`, `maximumAge: 0` (사양서 5.1)
- 모션: `accelerationIncludingGravity`(m/s²), `rotationRate`(deg/s → rad/s). 축: `rotationRate.beta`→`rx`, `gamma`→`ry`, `alpha`→`rz` (W3C DeviceOrientation 정의)
- 아이폰 모션 권한 `DeviceMotionEvent.requestPermission()`은 버튼 탭 처리에서 **await 전에** 호출
- 시각: 세션 시작 때 `performance.now()`·`Date.now()` 쌍 기록. 샘플 시각은 "세션 시작부터 ms"(세션 시계). GPS는 `tRecv`(세션 시계)와 `tFix`(`position.timestamp`, epoch ms) 둘 다
- 중단 후 이어서 하기: 새 페이지의 `performance.now()`는 0부터라, 세션 시계 오프셋을 `Date.now() − startedAt`으로 다시 잡는다
- 덩어리 저장 주기 5초 (`src/engine/config.ts`가 아니라 기록기 설정. 엔진 임계값이 아님)
- 원본 파일 자릿수: 위경도 7, 가속도·회전 속도 3, 나머지 2
- `status`: `recording` → (`interrupted`) → `finished`. 미업로드 원본은 자동 삭제하지 않음
- `src/normalize/**`는 DOM 금지 (M1 규칙)

## Review Focus

1. 기록 중 화면이 가려졌다가(앱 전환·잠금) 돌아오는 경우 → 가려질 때 즉시 저장과 `pause`, 돌아오면 `resume`과 화면 꺼짐 방지 재요청
2. 기록 중 강제 종료 → 다시 열면 `recording`인 세션을 `interrupted`로 바꾸고 묻는다. 이어서 하면 `seq`가 이어지고 시각이 뒤로 가지 않는다
3. 센서 값이 없는 기기 (GPS 속도·방향 null, 자이로 없음, heading NaN) → null로 저장, 화면에 "값 없음"
4. 권한 거부 (위치·모션) → 기록 시작 시 거부 상태와 다시 켜는 방법을 플랫폼별로 표시
5. 저장 실패(공간 부족 등) → 기록 화면에 오류 표시, 버퍼는 버리지 않고 다음 저장 때 다시 시도
