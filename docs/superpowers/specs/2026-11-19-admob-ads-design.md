# 디고 광고 (AdMob 배너) 설계

2026-11-19 · 상태: **설계만** — 코드는 1.0.1 심사가 끝나고, 세영이 디고 AdMob 앱 번호·배너 번호를 준 뒤 시작한다.
시안: `docs/mock/2026-11-19-ads.jpg` (①~⑤). 세영 "ㅇㅇ 시안먼저" → 시안 → "ㅇㅋ 이렇게 해둬".

## 왜

수익. 다만 디고는 운전 앱이라 **안전과 믿음이 광고보다 먼저**다. 광고 때문에 운전 중 시선을 뺏기거나, 앱이 느려지거나, 심사에서 막히면 실패다.

## 목표 · 안 하는 것 · 실패로 보는 것

**목표**
- 정식 아이폰 앱의 **코스·기록·설정 탭** 화면에만, 아래 탭 바 바로 위에 AdMob 배너 한 줄.
- 처음 한 번 애플 **추적 허락 창**. 허용하지 않아도 광고는 나온다(맞춤만 빠진다).
- 통신이 없거나 광고를 못 받으면 띠를 숨기고 자리도 접는다.
- 테스트 빌드(1.1, TestFlight)는 **구글 시험용 광고만** 보여 준다.

**안 하는 것**
- 화면 전체를 덮는 광고, 보상 광고, 네이티브(목록 속) 광고.
- 웹 광고(애드센스). github.io 하위 경로 주소로는 신청이 어렵고, 앱 안 웹 화면에 애드센스를 띄우는 것은 구글 규정 위반이다.
- 광고 제거 결제, 안드로이드.
- 메인 지도, 주행 준비·주행·요약, 코스·기록·공개 코스 상세, 분석, 재생, 팀 주행, 환영·로그인, 도움말, 관리자 화면의 광고.

**실패로 보는 것**
- 주행 준비·주행 중(또는 끝낸 직후의 요약 화면)에 광고가 보인다.
- 광고가 목록·단추·시트(아래에서 올라오는 창)를 가린다.
- 광고 때문에 앱이 느려지거나, 산길(통신 없음)에서 빈 칸이 남는다.
- 세영이 진짜 광고를 눌러 AdMob 계정이 막힌다.
- 추적 창 문구나 개인정보 항목이 안 맞아 심사에서 거절된다.

## 제약

- 앱은 사이트를 앱 안에 넣은 구조다(Capacitor 8, Swift Package Manager, `ios/`). AdMob 배너는 **네이티브 화면으로 웹 화면 위에 얹힌다**. 그래서 목록 안에 끼울 수 없고, 웹에서 여는 시트·창을 덮을 수 있다.
- **1.0.1 심사 중에는 넣지 않는다.** 다음 정식 버전(1.0.2)에 넣는다. 테스트 빌드는 지금처럼 1.1(정식보다 높게, `docs/release/app-store.md` 버전 규칙).
- 정식·테스트 빌드는 Codemagic 작업 두 개로 나뉜다(`codemagic.yaml`의 `ios-release`·`ios-testflight`).
- 앱 번호·배너 번호는 비밀이 아니다(앱 안에 그대로 들어간다). `codemagic.yaml` 환경값과 `Info.plist`에 둔다.
- 개인정보 보호법: 광고 SDK가 구글(미국)로 보내는 것은 **국외 이전** 고지가 필요하다.
- 세영 규칙: 화면이 바뀌는 일은 시안 먼저(완료), 코드 수정·배포는 물어보고, 비밀값은 채팅·코드에 넣지 않는다.

## 방법 비교

1. **커뮤니티 플러그인 `@capacitor-community/admob` 8.4.2**
   - 좋은 점: 가장 빠르다. 배너·전면·보상 광고와 구글 동의 창(UMP)이 다 들어 있다.
   - 걸리는 점: SPM 의존성에 출처를 모르는 `github.com/webview-native-ui/engine`(버전 `from: 1.0.10`, 고정 안 됨)이 같이 들어온다. 쓰지 않는 기능도 많다.
2. **우리 플러그인 `DgoAds` (고른 방법)**
   - 배너 띄우기·숨기기와 추적 허락만 하는 작은 네이티브 플러그인이다. 구글 Mobile Ads SDK(SPM, 정확한 버전 고정)만 쓴다.
   - 이미 있는 `DgoAuthPlugin`과 같은 방식이다.
   - 걸리는 점: 스위프트 코드 150줄 안팎을 우리가 관리한다. SDK를 올릴 때 직접 올린다.
3. **웹 화면 안 광고(애드센스·WebView API for Ads)**: 뺐다. 앱 화면 주소가 `capacitor://localhost`라 사이트 승인을 받을 수 없고, 애드센스를 앱 웹 화면에 띄우는 것은 규정 위반이다.

**고른 것: 2.** 세영이 방법을 맡겼고("이렇게 해둬"), 필요한 기능이 작다. 이렇게 하면 모르는 바깥 코드가 빌드에 섞이지 않는다.

## 설계

### 보이는 곳 (시안 ①~④)

광고는 아래 조건이 **모두** 맞을 때만 보인다.
- 아이폰 앱 빌드(`isApp()`)이고 그 빌드에 배너 번호가 있다.
- 지금 화면이 탭 화면 `#/courses`·`#/history`·`#/settings`이다(`Tabbed`에서 그 세 경로일 때만 광고 자리를 쓴다).
- 주행 단계가 `idle`이고 재생 중이 아니다(`getDriveState()`). 주행을 시작하면 바로 숨긴다.
- 열린 시트·창이 없다. `Overlay`로 여는 모든 창의 개수를 세어, 하나라도 열려 있으면 숨긴다. 배너가 창의 아래 단추를 덮지 않게 하려는 것이다.
- 앱이 화면 앞에 있다(백그라운드로 가면 숨긴다).
- 광고를 실제로 받았다.

**위치와 크기**
- 탭 바 바로 위, 화면 가로를 꽉 채우는 **앵커형 적응 배너**다(높이는 기기마다 50~62).
- 탭 바와 붙지 않게 사이에 1px 구분선을 둔다. 잘못 누르는 것을 줄이려는 것이다(AdMob 배치 정책).
- 웹 쪽 `Tabbed` 본문 아래 여백 = 광고 높이(CSS 변수 `--ad-h`, 광고가 없으면 0). 그래서 목록의 끝이 띠 위에서 끝난다.
- 네이티브에는 "화면 아래에서 얼마나 띄울지(= 탭 바 높이, 안전 영역 포함)"를 웹이 재서 넘긴다.

### 추적 허락 (시안 ⑤)

- 시점: 앱 설치 후 **광고 탭을 처음 열 때 한 번**. 환영·로그인이 끝난 뒤이고 주행 중이 아닐 때다. 답하기 전에는 광고를 요청하지 않는다. 답이 허용이든 거절이든 그 뒤에 광고를 요청한다.
- 문구(`NSUserTrackingUsageDescription`): **"허용하면 관심 있을 만한 광고가 나와요. 허용하지 않아도 앱은 똑같이 쓸 수 있어요."**
- iOS가 한 번만 묻는다. 나중에 바꾸려면 아이폰 설정 › 개인정보 보호 › 추적이다(개인정보 처리방침에 적는다).

### 받기와 실패

- 광고 탭에 처음 들어갈 때 Mobile Ads를 한 번 시작하고 배너를 받는다.
- 실패하면(통신 없음, 채울 광고 없음) 숨기고 자리를 접는다. 다음에 광고 탭으로 갈 때 다시 받는다. 단, 마지막 시도에서 **60초가 안 지났으면 다시 받지 않는다**.
- 탭을 옮겨 다닐 때는 받은 배너를 다시 쓴다(숨기고 보이기만). 광고 자동 새로고침은 AdMob 콘솔 설정을 따르고 앱에서는 따로 하지 않는다.
- 광고 SDK가 응답하지 않아도 화면은 기다리지 않는다. 배너 호출은 `nativeCall`(5초) 안에서 하고, 실패는 "광고 없음"으로 친다.

### 빌드별 광고 번호

| 빌드 | 배너 번호 | 앱 번호(`GADApplicationIdentifier`) |
|---|---|---|
| 정식 `ios-release` (1.0.2~) | `VITE_ADMOB_BANNER` = 세영이 준 디고 배너 번호 | 디고 앱 번호 |
| 테스트 `ios-testflight` (1.1) | 구글 iOS 배너 시험 번호 `ca-app-pub-3940256099942544/2435281174` | 디고 앱 번호(같은 값) |
| 웹·개발 서버 | 없음 → 광고 코드가 돌지 않음 | — |

- `Info.plist`는 두 빌드가 같다(앱 번호 하나).
- 배너 번호는 빌드 환경값으로 정한다. 정식 작업에 값이 없으면 광고가 꺼진다. 실수로 테스트 빌드에 진짜 광고가 나가지 않게 하려는 것이다.

### 네이티브 (`DgoAds`)

- 구글 Mobile Ads SDK를 SPM으로 **정확한 버전**을 고정해서 넣는다(`swift-package-manager-google-mobile-ads`).
- 함수:
  - `trackingStatus()` → `notDetermined | authorized | denied | restricted`
  - `requestTracking()` → 위와 같은 값
  - `showBanner({ adUnitId, bottom })` → 이벤트 `adLoaded { height }`·`adFailed { message }`
  - `hideBanner()`
- `bottom`은 웹이 잰 탭 바 높이(pt)다. 배너는 안전 영역 아래쪽에서 `bottom`만큼 위에 놓는다.
- `Info.plist`에 `GADApplicationIdentifier`, `NSUserTrackingUsageDescription`, `SKAdNetworkItems`(구글이 주는 목록)를 넣는다.
- `PrivacyInfo.xcprivacy`: 구글 SDK에 자체 매니페스트가 있다. 앱 매니페스트에 추적 선언(`NSPrivacyTracking`)이 필요한지는 만드는 사람이 확인해서 맞춘다.

### 웹 쪽

- `src/app/ads.ts`(앱 빌드에서만 움직임)
  - 상태 `{ visible, height }`와 위 "보이는 곳" 조건을 한곳에서 판단한다.
  - 주행 상태 구독, 열린 창 개수, 앱 앞·뒤(`@capacitor/app`)를 본다.
- `Tabbed`: 광고 탭 세 곳에서 광고 자리를 켜고, `--ad-h`로 본문 여백을 준다.
- `Overlay`: 열릴 때와 닫힐 때 `ads.ts`에 알린다(열린 개수).
- `features.ts`에 `adsEnabled()` = 앱 빌드 + 배너 번호 있음.

### 문서·심사

- **개인정보 처리방침**에 광고 항목을 더한다.
  - 구글 AdMob이 받는 것: 광고 식별자(허용한 경우만), IP·기기 정보, 광고 본 것·누른 것
  - **국외 이전**: 이전받는 자 Google LLC, 국가 미국, 목적 광고 표시, 보유 기간은 구글 정책
  - 거부 방법: 아이폰 설정 › 개인정보 보호 › 추적
- **App Store 개인정보 항목**: 구글 "데이터 공개" 안내대로 고친다.
  - 식별자 › 기기 ID: 제3자 광고, 추적
  - 사용 데이터 › 광고 데이터: 제3자 광고
  - 그 밖에 구글이 적으라는 항목(대략적 위치·진단 등)
  - 맨 위 "추적에 쓰나요?"를 **예**로
- **심사 메모**: 광고 위치(코스·기록·설정 탭만, 주행 화면 없음)와 추적 창 설명.
- **app-ads.txt**(AdMob 판매자 확인): 앱스토어 "개발자 웹사이트" 도메인의 맨 위에 둬야 한다. `chungyakgo-maker.github.io/gachitayo/`는 하위 경로라 안 된다. 없어도 광고는 나오지만 덜 채워질 수 있다(아래 세영 결정).
- `docs/아이폰-앱-진행기록.md`의 "광고 없음" 줄을 이 설계로 고친다.

### 시험

- **단위**: `ads.ts` 보이기 조건 표를 시험한다.
  - 광고 탭이 아니면 숨김
  - 주행 준비·주행·끝내는 중이면 숨김
  - 창이 열리면 숨김, 닫히면 다시 보임
  - 받기 실패 → 접기 → 60초 안에는 다시 받지 않음
  - 웹 빌드면 아무것도 안 함
  - 추적 답 전에는 광고 요청 안 함
- **화면**: `Tabbed` 여백이 광고 높이만큼, 시트를 열면 숨김.
- **실기기**(TestFlight 1.1, 시험 광고):
  - 세 탭에서 보이고, 메인·주행에서는 안 보임
  - 비행기 모드에서 접힘
  - 추적 창이 한 번 뜸
  - 시트를 열면 사라짐
- **시뮬레이터 빌드 CI**("아이폰 앱 빌드 (시뮬레이터)")가 통과해야 한다.

## 세영이 정할 것·줄 것

1. **디고 AdMob 앱 번호**(`ca-app-pub-…~…`)와 **배너 번호**(`ca-app-pub-…/…`). AdMob › 앱 추가 › iOS › 디고, 그 앱의 광고 단위 › 배너. 메리고 번호는 쓰지 않는다.
2. **판매 국가**: 대한민국만이면 구글 동의 창(UMP)을 넣지 않는다. 유럽·영국이 들어가면 UMP 동의 창을 추적 창보다 먼저 넣는다(이 경우 범위가 커진다).
3. (나중) **app-ads.txt 둘 곳**: 도메인을 하나 사서 개발자 웹사이트로 쓰거나, `chungyakgo-maker.github.io` 저장소를 따로 만든다.

## 만드는 사람에게 맡긴 것

- `DgoAds`를 앱 타깃 안 클래스로 둘지(`DgoAuthPlugin`처럼 `MainViewController`에서 등록), 로컬 Capacitor 플러그인 패키지로 둘지. 구글 SDK를 SPM으로 잇기 쉬운 쪽으로.
- 배너 다시 받기의 세부(60초 기준 안에서), 배너 높이 전달 방식.
- `SKAdNetworkItems` 최신 목록, 구글 SDK 버전(설계 때 최신 안정판, 정확히 고정).
