# 메인 검색·코스 분류·즐겨찾기·인기 도로·코스 누르면 출발점 안내·주행 지도 확대축소 설계

2026-11-16 · 사용자 요청과 시안 확인 (시안 사진: 메인 검색창+분류 칩, 메인 검색 결과, 코스 누르면 창, 코스 목록, 주행 지도 +/−)

## 사용자 결정 (대화 그대로)

- "최상단 새코스 없애, 검색창 하나 만들어서 목적지 검색" → 메인 맨 위 카드(새 코스 / 현재 위치에서 감지됨)를 빼고 검색창
- "주행 모드중 지도 축소나 확대 할수 있게" → 주행 지도 + / − 버튼
- "메인 지도화면에서 설정된 지도 누르면 출발지로 바로 이동하게(출발지, 도착지 확인하게, 지도 보여주면서)" → 코스 선을 누르면 창: 출발·도착 핀 지도, 출발점으로 길찾기
- "내가 설정한 경로만 보기, 전체 보기", "코스에 즐겨찾기 … 메인지도에 보라색" → 분류 칩 + 즐겨찾기 보라 선
- 분류: "코스마다 직접 고르기", "와인딩 이건 없애, 산길로" → 분류는 **해안 길 · 산 길** 둘. 기본 코스 17개는 처음 값 산 길
- 인기 도로 기간: "최근30일, 최근7일, 전체기간, 계절(봄,여름,가을,겨울), 실시간"
- 실시간: "이 코스 주행 중" 신호만 2분마다 (위치 없음), 최근 10분 안에 신호 온 사람 수 (제안, 이의 없음)

## 칩 (메인 지도·코스 목록 같은 줄)

전체 · 기본 코스 · ★ 즐겨찾기 · 내 코스 · 해안 길 · 산 길 · 인기 도로.
인기 도로를 고르면 둘째 줄: 실시간 · 7일 · 30일 · 전체 · 봄 · 여름 · 가을 · 겨울 (기본 30일).
고른 칩은 설정에 남는다 (메인·코스 목록이 같이 쓴다). 예전 "코스 보기 켜짐/꺼짐" 칩은 없앤다.

## 데이터

- 즐겨찾기·분류: 계정에 저장 (`GET/PUT /api/prefs`, D1 `user_prefs`, JSON 16 KB 이하), 폰에도 둔다(localStorage). 열쇠는 기본 코스 `b:{key}`, 내 코스 코스 id.
  분류 값 `coast`(해안 길)·`mountain`(산 길). 기본 코스는 지정이 없으면 `mountain`.
- 인기: `GET /api/popular?period=live|7d|30d|all|spring|summer|autumn|winter` → `[{builtin, drivers}]` (많은 순, 최대 20).
  달린 사람 수 = 그 기간에 그 기본 코스로 올라온 기록의 서로 다른 계정 수. 계절은 해와 상관없이 그 달(한국 시각): 봄 3~5, 여름 6~8, 가을 9~11, 겨울 12~2.
  실시간 = D1 `driving_now`에 최근 10분 안에 신호를 보낸 계정 수. 신호: `POST /api/driving {builtin}` (기본 코스로 주행 중일 때 2분마다).
- 내 코스는 남이 못 보므로 인기 순위에 없다.

## 화면

- 메인: 맨 위 검색창(장소·주소, 네이버 지역 검색). 결과를 누르면 목적지 화면으로 넘어가 경로를 받는다(위치가 아직이면 받는 대로).
  그 아래 주행 시작, 분류 칩(+인기 기간 칩), 위치 공유 칩. 지도는 칩에 맞는 코스만, 즐겨찾기는 진한 보라(#b15cff, 굵게), 나머지 빨강.
  코스 선을 누르면 창: 이름·★·편도/랩·길이·커브 수, 출발·도착 핀 지도(코스 상세와 같은 지도), 출발점까지 직선 거리,
  [출발점으로 길찾기] (목적지 화면으로, 목적지 = 출발점), [이 코스로 주행], 닫기.
- 코스 목록: 같은 칩. 줄마다 ☆/★, 분류 표시(해안 길·산 길), 인기 도로면 "N명"과 순서.
- 코스 상세: ★ 즐겨찾기, 분류 고르기(해안 길·산 길 켜기/끄기).
- 주행 지도: 오른쪽 + / − (설정 `driveZoom`, −4~+2, 남는다). 따라가기·진행 방향 보기는 확대 단계만큼, 전체 보기는 맞춘 뒤 그만큼.
  바탕 지도 없을 때(캔버스)는 보이는 거리 ×2^−단계. 두 번 탭(모드 바꾸기)으로 치지 않는다.

## 개인정보 (ios 갈래 privacy.html)

즐겨찾기·분류는 계정에 저장. 기본 코스로 주행 중이면 "이 코스 주행 중" 신호(위치 없음)를 보내 실시간 인기에 센다(10분 지나면 안 셈).

## 하지 않을 것

와인딩 분류, 내 코스 인기 순위, 코스 이름 바꾸기 외 편집, 출발점 도착 뒤 자동으로 코스 주행으로 바꾸기.
