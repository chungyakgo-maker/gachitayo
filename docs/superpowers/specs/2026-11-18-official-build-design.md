# 정식 버전 빌드 (위치 공유 끔) 설계

2026-11-18 · 세영 "정식 배포용(위치공유 없애고) 미리 설계", "저녁에 진행". 시안: `docs/mock/2026-11-18-official-build.jpg` (왼쪽 지금 · 오른쪽 정식).
**아직 코드는 바꾸지 않았다.** 시안 승인 뒤 계획 → 구현.

## 왜

위치기반서비스사업 신고(사업자등록 필요) 전에 앱스토어 정식 출시를 하려고, **다른 사람과 서로 위치를 주고받는 기능만** 정식 빌드에서 끈다. 신고가 끝나면 다시 켠다.

## 세영 결정 (대화 그대로)

- "정식버전엔 위치공유를 빼고 추후에 사업자등록/신고 후에 재활성화 예정"
- "팀 방은 유지하고, 지도상 서로 위치공유만 안 하고 모든 기능은 유지", "목적지 설정값도 동일하게" (방장 목적지 같이 받기 유지)
- 추천대로: 단추는 **숨김**("업데이트 예정" 창 아님 — 애플 2.1 미완성 거절 위험), 방장 차 간격은 **안내 문구로만**, **웹도 같이 숨김**
- 기록 서버 올리기·목적지 길찾기는 그대로 (위치정보지원센터 문의 때 같이 묻기)
- 따로 저장소·복사본을 만들지 않고 **같은 코드 + 빌드 스위치** (세영 "ㅇㅇ 해봐")

## 방식

- 빌드 스위치 `VITE_LOCATION_SHARING` (`on` 기본 · `off` 정식). 앱 코드는 `src/platform.ts`의 `locationSharing(): boolean` 한 곳만 본다.
- 서버에서 원격으로 켜지 않는다 (심사 뒤 숨긴 기능을 켜면 애플 2.3.1 위반). 다시 켤 때는 스위치 `on`으로 빌드해 업데이트 심사.
- Codemagic 작업 둘: 지금 "디고 아이폰 → TestFlight"(on, 테스트), 새 "디고 아이폰 정식 → App Store"(off). 웹은 정식 출시 때 `off`로 배포.
- 서버는 그대로 둔다 (예전 빌드·테스트 빌드가 쓴다). 정식 빌드가 안 보내면 서버에 위치가 가지 않는다.

## 끄면 막는 것 (보내기·받기 — 화면만 숨기지 않는다)

- `/api/presence` PUT·DELETE (setSharing) 안 함, `GET /api/friends/presence` 안 함 (friends.ts)
- 친구 실시간 연결 `/live/{id}` 안 엶 (liveLink.ts startLiveLinks, drive.ts)
- 팀 방 웹소켓: 연결은 함(상태: 순서·간격·목적지), **내 GPS 안 보냄**, 받은 `pos`는 버림 (group.ts connect/onMessage)
- 저장된 설정: `deltaSource: 'friend'` → 'best', 칸 `gap` → 'none'으로 읽음 (설정 값은 지우지 않음 — 다시 켜면 그대로)

## 그대로

기록(서버 올리기)·분석·코스·목적지 길찾기·표지판·팀(만들기·대기실·목적지 같이 받기·카톡 알리기)·친구·프사·로그인·실행 애니메이션.

## 시험 (구현 때)

- 스위치 `off`로 앱을 띄우고 fetch·WebSocket을 가로채, 주행·메인·팀 주행 동안 **위치 좌표가 실린 요청이 목적지 길찾기·기록 올리기 말고는 하나도 없음**을 확인
- 각 화면에서 숨김 항목이 없는지(시안 표 그대로), `on` 빌드는 지금과 똑같은지(기존 테스트 전부 통과)

## 정식 출시 때 같이 할 것

- 개인정보 처리방침·위치정보 이용약관: 위치 공유 문장을 "현재 제공하지 않음(추후 제공)"으로 (웹 페이지는 하나라 정식 출시 때 웹도 off로 배포하며 바꾼다)
- App Store 개인정보 라벨: 정확한 위치 — 앱 기능(기록·길찾기), 사용자와 연결됨. "다른 사용자와 공유" 없음
- 심사 메모: 팀 주행은 순서·목적지만 함께, 위치 공유 없음

## 다시 켜기

사업자등록 → 위치기반서비스사업 신고 → 정식 작업 스위치 `on` → 약관·라벨 되돌림 → 업데이트 심사.

## 세영에게 물을 것 (구현 전)

1. 팀 주행 화면 아래 순서 줄(1 세영 · 2 민수)은 남김 — 추천(위치가 아님). 빼고 싶으면 말씀
2. 정식 빌드 버전 번호: 1.0.0으로 시작(테스트 빌드는 지금처럼 빌드 번호만 올림) — 추천
