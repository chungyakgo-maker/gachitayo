# 팀 · 팀 주행 · 프로필 사진 설계

2026-11-18 · 사용자 요청과 시안 확인("ㅇㅇ 진행해 업로드방식으로만"). 시안: 주행 시작, 팀 고르기, 팀 대기실, 팀 만들기, 메인 "주행 중" 알림, 설정 친구·팀, 프로필 사진.

## 왜

같이 달리는 사람들이 매번 방을 만들고 코드를 카톡으로 돌리지 않게, **친구로 만든 팀을 계속 두고** 그 팀으로 바로 달린다. 이름도 "그룹 주행" → "팀 주행".

## 사용자 결정 (대화 그대로)

- "팀 만들기 → 최대 인원 15명, 친구 등록한 인원들을 넣어"
- "주행 시작 → 그룹 주행 (팀 주행으로 변경) → 팀이 여러 개면 선택 후 해당 팀으로 주행 (팀은 최대 5개)"
- A-가: 방 코드·코드로 들어가기·방 코드 카톡 초대는 없앤다. 팀원은 친구에서만. 카톡 초대는 **친구 초대**로(받은 사람이 누르면 바로 친구)
- B-가: 팀 5개는 **내가 속한 팀 전체**(만든 팀 + 들어간 팀). 5팀인 친구는 새 팀에 못 넣고 "팀이 가득 찬 친구"로 보인다
- 프로필 사진: "아주 작은 프사 동그랗게", **폰에서 올리기만**(카카오 사진 가져오기 없음)

## 제 결정 (시안에 적어 알림, 사용자 승인)

- 만든 사람 = 팀장: 이름·팀원 넣기/빼기·팀 지우기. 팀원: 팀 나가기. 팀장이 나가려면 팀 지우기
- 친구를 넣으면 묻지 않고 바로 팀원. 나중에 친구를 끊어도 팀에서는 안 빠진다(팀장이 빼면 빠짐)
- 팀 주행은 팀원 누구나 연다. **연 사람이 그 주행의 방장**(순서·차 간격·목적지). 이미 열려 있으면 거기로 들어간다
- 순서·차 간격은 팀마다 기억해 다음 주행에 그대로
- 팀이 1개면 "팀 주행"을 누르자마자 대기실, 여러 개면 팀 고르기, 없으면 팀 만들기
- 알림(푸시)이 없으므로 대기실에 "카카오톡으로 '주행 열었어요' 알리기"(누르면 그 팀 대기실로)
- 메인 화면 맨 위: 내 팀이 주행을 열었으면 "○○팀 주행 중 · N명 · 들어가기"
- 15명이면 색 8가지를 돌려 쓰고(가장 적게 쓴 색) 번호로 구별
- 프사: 가운데를 정사각형으로 잘라 160×160 JPEG로 줄여 올림. 화면에는 26px 동그라미(내 프로필 76px). 없으면 닉네임 첫 글자 동그라미.
  보이는 곳: 친구 목록 · 팀 만들기/편집 · 팀 대기실(+안 들어온 팀원). 주행 지도에는 안 넣음
- 프사는 나와 친구이거나 같은 팀인 사람에게만 주소가 간다(주소 = 맞힐 수 없는 무작위 id). 탈퇴·지우기 때 서버에서도 지움

## 하지 않을 것

팀 채팅, 팀장 넘기기, 팀 초대 수락 단계, 카카오 프로필 사진, 주행 지도 프사, 정식 버전 위치 공유 끄기(따로 구상해 둠).

## 구조

### 서버 (Worker + D1 + R2) — 지금 방 API는 그대로 둔다

지금 배포된 웹·TestFlight 빌드가 방 코드를 쓰므로 `/api/rooms`·`/api/rooms/join`은 남긴다(더하기만 함).

- D1 0011:
  - `teams(id, name, owner_id, created_at, gap_s, order_json, drive_room_id)`
  - `team_members(team_id, user_id, added_at)` — 팀장도 행이 있다
  - `users.avatar` (무작위 id, 없으면 NULL)
- 프사: R2(SESSION_FILES) `avatars/{id}.jpg`. `GET /avatar/{id}.jpg` 는 열쇠 없이 준다(오래 저장 가능, 새로 올리면 새 id)
  - `PUT /api/me/avatar` (image/jpeg 본문, 100KB까지, JPEG 머리 확인) → `{avatar}` · `DELETE /api/me/avatar`
- `GET /api/friends`: 친구마다 `avatar`, `full`(그 친구가 팀 5개) 추가. `GET /api/me`에 `avatar`
- 팀 API (모두 로그인)
  - `GET /api/teams` → `{teams:[{id, name, ownerId, members:[{userId, nickname, avatar}], gapS, drive:{roomId, count}|null}]}`
  - `POST /api/teams {name, memberIds}`: 이름 1~20자, 팀원은 내 친구만, 나 포함 15명, 내 팀 5개 미만, 넣는 친구도 5개 미만
  - `PUT /api/teams/{id} {name?, memberIds?}` (팀장만, memberIds는 팀장 뺀 전체 목록)
  - `DELETE /api/teams/{id}` (팀장만) · `POST /api/teams/{id}/leave` (팀원만)
  - `POST /api/teams/{id}/drive` (팀원만) → `{roomId}`: 열린 주행이 살아 있으면 들어가고, 없으면 새 방(연 사람 방장, 팀 순서·간격으로)
- GroupRoom(방): `teamId`·`teamName`·`max`(코드 방 8, 팀 방 15)·참가자 `avatar` 추가. 팀 방은 팀 순서대로 자리 잡기. 다 나가면 방을 닫는다.
  방장이 순서·간격을 바꾸면 Worker가 팀에도 저장
- 탈퇴: 내가 팀장인 팀 지우기, 팀원 행 지우기, 프사 파일 지우기

### 앱

- `src/app/teams.ts`: 팀 목록(30초마다, 메인이 보일 때) · 만들기 · 고치기 · 지우기 · 나가기 · 팀 주행 열기(→ 방 열기)
- `src/app/avatar.ts`: 사진 → 정사각형 160×160 JPEG · 올리기 · 지우기
- `group.ts`: 방 상태에 `teamId`·`teamName`·참가자 `avatar`, 방 id로 바로 들어가기
- 화면: 주행 시작 "팀 주행", 팀 고르기 창, 팀 만들기/편집 화면(`#/team/new`, `#/team/{id}`), 팀 대기실(방 코드 대신 알리기, 안 들어온 팀원, 프사), 메인 알림,
  설정 "내 프로필"(프사) · 친구(프사, 카톡 친구 초대) · 팀 카드, 친구 초대 링크 `#/friend/{코드}` → "친구가 될까요?"
- 팀 주행 알리기 링크 `#/team/{id}/drive` → 팀원이면 대기실로
- 아이폰: 사진 고르기에서 "사진 찍기"가 카메라를 쓰므로 Info.plist 카메라·사진 사용 문구
- 개인정보 처리방침: 프로필 사진(선택)·팀 정보

## 빌더에게 맡긴 것

함수·파일 나누기, 오류 문구 세부, 테스트 구성(서버는 workers 테스트, 앱은 vitest).
