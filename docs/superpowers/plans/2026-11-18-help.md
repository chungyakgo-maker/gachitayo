# 도움말 · 기능 알아보기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설정 › 도움말 › "기능 알아보기" 페이지(`#/help`)와 메인의 처음 한 번 알림을, 실제 앱 화면 스크린샷 + GIF 2개로 만든다 (정식 기준, 친구 위치 공유 없음).

**Architecture:** 카드 내용은 데이터 한 곳(`src/ui/help/helpCards.ts`)에 두고 화면(`HelpScreen.tsx`)은 그것만 그린다. 그림은 `public/help/`에 두어 웹·앱 빌드에 그대로 들어간다(통신 없어도 보임). 그림은 저장소의 대본(`scripts/help-media.cjs`)이 정식 스위치로 띄운 앱에서 찍는다.

**Tech Stack:** React 19, Vite 8, Vitest + Testing Library, Playwright(그림 찍기), ffmpeg(GIF).

**Spec:** `docs/superpowers/specs/2026-11-18-help-design.md` · 시안 `docs/mock/2026-11-18-help.jpg`

## Global Constraints

- 정식 기준: 페이지 어디에도 "위치 공유"·"앞 친구"·"친구 위치" 글자가 없다 (테스트 빌드에서도 같은 페이지)
- GIF는 정확히 2개: `public/help/pace.gif`(커브 표지판), `public/help/bike.gif`(바이크 기울기). 나머지 그림은 JPEG
- 그림 크기: JPEG 장당 ≤ 150 KB(가로 720 px 안팎), GIF 장당 ≤ 1.5 MB(가로 360 px 안팎, 초당 10장, 3~4초 반복), `public/help/` 전체 ≤ 4 MB
- 모든 `<img>`에 `alt`(카드 제목과 같은 말), GIF는 `prefers-reduced-motion`이면 첫 장(같은 이름 `.jpg` 정지 그림)
- 카드 순서·문구는 설계 문서 "카드" 표 그대로. 설명 끝맺음은 "~해요"
- 메인 알림 기억 키: `gachitayo.helpNudge.v1` (값 `'1'`이면 다시 안 띄움)
- 색은 기존 CSS 변수만 (`--card`, `--card-line`, `--fg`, `--fg-2`, `--fg-dim`, `--accent`)

## Review Focus

- 칩을 눌렀을 때 고정된 머리줄 밑에 카드 제목이 가려지지 않는다 → Task 2 테스트: 칩 클릭이 그 카드의 `scrollIntoView`를 부른다 + CSS `scroll-margin-top`
- 그림 파일이 빠졌거나 이름이 틀리면 빈 상자 → Task 3 테스트: 카드가 가리키는 파일이 `public/help/`에 다 있다
- 메인에 팀 주행·방 알림이 떠 있을 때 도움말 알림이 겹쳐 쌓인다 → Task 2 테스트: 팀 알림이 있으면 도움말 알림 없음
- 정식 빌드인데 설명에 위치 공유가 섞임 → Task 1 테스트: 모든 카드 글에 금지 낱말 없음
- 움직임 줄이기를 켠 사람에게 GIF가 계속 움직임 → Task 2 테스트: `matchMedia('(prefers-reduced-motion: reduce)')`면 `.jpg` 정지 그림

### Task 1: 카드 데이터

**Files:**
- Create: `src/ui/help/helpCards.ts`
- Test: `test/ui/helpCards.test.ts`

**Interfaces:**
- Produces:
  - `export interface HelpCard { id: string; title: string; chip: string; media: { src: string; kind: 'jpg' | 'gif' } | null; lines: string[]; link?: { href: string; label: string } }`
  - `export const HELP_START: string[]` (처음 3단계 글 3줄)
  - `export const HELP_CARDS: HelpCard[]` (설계 표 순서: `lap`, `pace`, `dest`, `course`, `team`, `bike`, `history`, `screen`)
  - `media.src`는 `help/<id>.jpg` 또는 `help/<id>.gif` (상대 주소, 앱·웹 둘 다 맞게)

- [ ] **Step 1: 실패하는 테스트**
  - `HELP_CARDS.map(c => c.id)`가 `['lap','pace','dest','course','team','bike','history','screen']`
  - `gif`가 정확히 `pace`·`bike` 둘
  - 모든 카드 `lines.length` 2~3, `chip`·`title` 비지 않음
  - 모든 글(`HELP_START`, title, lines, link.label)에 `/위치 공유|앞 친구|친구 위치/` 없음
  - 링크: `dest` → `#/destination`, `course` → `#/courses`, `bike` → `#/settings`, `history` → `#/history`
- [ ] **Step 2: 실행해 실패 확인** — `npx vitest run test/ui/helpCards.test.ts` → FAIL (모듈 없음)
- [ ] **Step 3: 구현** — 설계 문서 "카드" 표의 내용 칸 문구를 그대로 2~3줄로. 처음 3단계는 설계 표 첫 줄
- [ ] **Step 4: 통과 확인** — 같은 명령 PASS
- [ ] **Step 5: 커밋**

### Task 2: 화면 — 기능 알아보기 페이지, 설정 링크, 메인 알림

**Files:**
- Create: `src/ui/screens/HelpScreen.tsx`, `src/ui/components/HelpNudge.tsx`
- Modify: `src/ui/App.tsx` (`case '/help'`), `src/ui/screens/SettingsScreen.tsx` (약관 위 "도움말" 칸), `src/ui/screens/MainScreen.tsx` (`<TeamNotice />` 바로 아래 `<HelpNudge />`), `src/ui/styles.css`
- Test: `test/ui/help.test.tsx`

**Interfaces:**
- Consumes: `HELP_START`, `HELP_CARDS` (Task 1)
- Produces: `export function HelpScreen(): ReactElement`, `export function HelpNudge(): ReactElement | null`, `export const HELP_NUDGE_KEY = 'gachitayo.helpNudge.v1'`

- [ ] **Step 1: 실패하는 테스트**
  - 설정: 이름 "도움말"인 구역 안에 `기능 알아보기` 링크, `href="#/help"`
  - `HelpScreen`: 제목 "기능 알아보기", "처음이세요? 3단계면 돼요", 카드 제목 8개가 순서대로(`getAllByRole('heading', { level: 2 })`), 뒤로 링크 `#/settings`
  - 칩 "커브 표지판" 클릭 → 그 카드 요소의 `scrollIntoView`가 불림 (jsdom이라 `Element.prototype.scrollIntoView = vi.fn()`)
  - 그림: `pace` 카드 img `src`가 `help/pace.gif`, `alt` "커브 표지판"; `matchMedia` 가짜가 reduce면 `help/pace.jpg`
  - 링크 카드: "목적지 고르기" 링크 `href="#/destination"`
  - 페이지 글 전체에 `/위치 공유/` 없음
  - `HelpNudge`: 저장값 없으면 "디고 처음이세요?" 보임, "기능 알아보기" 누르면 `HELP_NUDGE_KEY`='1' 저장 + 주소 `#/help`; ✕(이름 "알림 닫기") 누르면 저장 후 사라짐; 저장값 있으면 안 보임; 팀 주행 알림이 뜰 팀이 있으면(useTeams에 drive.count>0) 안 보임
- [ ] **Step 2: 실행해 실패 확인** — `npx vitest run test/ui/help.test.tsx` → FAIL
- [ ] **Step 3: 구현**
  - 페이지: 시안 ③~⑤ 그대로 (`page-head` + 뒤로, 3단계 카드, 가로로 밀리는 칩 줄, 카드 = `h2` · 그림 · `ul` · 바로 가기). 카드 `id="help-<id>"`, CSS `scroll-margin-top`으로 머리줄에 안 가리게. GIF 그림 오른쪽 아래에 "움직이는 그림" 작은 표시
  - 메인 알림: 시안 ① 모양, `notice` 계열 클래스, 팀·방 알림이 있으면 숨김. 저장은 try/catch(사생활 보호 모드)
  - 설정: 시안 ② — 약관 구역 바로 위, `list-link` "기능 알아보기" + 부제 "그림으로 보는 디고 사용법"
- [ ] **Step 4: 통과 확인** — 같은 명령 PASS, `npx tsc --noEmit -p .` 오류 0
- [ ] **Step 5: 커밋**
