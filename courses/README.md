# 기본 코스 직접 올리기

여기에 코스 폴더를 올리면, 배포가 끝난 뒤 웹과 앱(1.0.4부터)의 **기본 코스**에 들어갑니다. 앱 심사는 필요 없습니다.

## 코스 하나 = 폴더 하나

```
courses/
  영암 새 코스/        ← 폴더 이름은 아무거나 (한글 가능). 한 번 정하면 바꾸지 마세요
    정보.txt
    아무이름.gpx       ← GPX 는 폴더에 딱 하나
```

## 정보.txt

한 줄에 `항목: 값` 하나씩. 맨 앞이 `#` 인 줄은 메모라 무시합니다.

```
이름: 영암 KIC 상설코스
지역: 전남 영암 · 서킷 한 바퀴
분류: 서킷
설명: 길이 3.045 km, 코너 11개
설명: 일반 스포츠주행과 트랙데이는 주로 이 코스에서 열려요
트랙: 영암상설
```

| 항목 | 꼭? | 내용 |
|---|---|---|
| 이름 | 꼭 | 코스 목록에 보이는 이름 |
| 지역 | 꼭 | 이름 아래 작은 글 (예: `춘천 → 화천`, `강원 인제 · 서킷 한 바퀴`) |
| 분류 | | `서킷` · `산 길` · `해안 길` (여러 개면 쉼표). 없으면 산 길 |
| 설명 | | 코스 상세 맨 위 상자에 한 줄씩. 여러 줄이면 `설명:` 을 여러 번 |
| 트랙 | | GPX 에 트랙이 여러 개일 때 쓸 트랙 이름. 하나면 안 써도 돼요 |
| 고침 | | 선(GPX)을 고쳐 다시 올릴 때 숫자를 하나 올려요 (처음은 안 써도 1). 올려야 이미 받은 폰의 선도 바뀌어요 |

- 한 바퀴 코스(서킷)는 GPX 를 **출발선에서 시작해 달리는 방향으로 한 바퀴 돌아 출발선에서 끝나게** 따 주세요. 시작점이 출발선이 됩니다.
- 편도 코스는 출발 → 도착 방향으로.
- `_` 로 시작하는 폴더(`_예시`)는 앱에 들어가지 않아요. 본떠 쓰는 견본입니다.

## GitHub 웹에서 올리는 순서 (PC)

1. 저장소 `main` 갈래에서 `courses` 폴더로 들어갑니다.
2. **Add file → Create new file** → 이름 칸에 `영암 새 코스/정보.txt` 처럼 **폴더 이름/정보.txt** 를 적고, 위 모양대로 내용을 붙여 넣은 뒤 **Commit changes**.
3. 방금 생긴 폴더로 들어가 **Add file → Upload files** → GPX 파일을 끌어다 놓고 **Commit changes**.
4. 저장소의 **Actions** 탭에서 "테스트·배포" 가 초록 체크가 되면 끝 (몇 분). 웹은 새로고침, 앱은 다시 열면 들어옵니다.
   - 빨간 X 면 파일이 틀린 것 — 눌러서 "기본 코스 (courses/ 폴더)" 칸을 보면 무엇이 틀렸는지 한국어로 나와요. 고쳐서 다시 올리면 됩니다. 틀린 동안은 배포되지 않아 원래 코스는 그대로예요.

## 고치기 · 빼기

- 이름·설명만 바꾸기: `정보.txt` 를 고쳐 Commit.
- 선 바꾸기: GPX 를 새 파일로 바꾸고(예전 GPX 는 지우기) `정보.txt` 의 `고침:` 숫자를 하나 올려 Commit.
- 빼기: 폴더를 지우면 새로 설치한 폰에는 안 들어가요. 이미 받은 폰에는 그대로 남아요 (그 코스 기록이 있을 수 있어서).
